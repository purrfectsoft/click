# 🖱️ Click!

**Shorten. Share. Track. Privately.**

Click! is the **Purrfect Universe’s open-source link and sharing tool** — built on **Expo Universal App** + **Tamagui** to make privacy-first link shortening, QR generation, and text sharing simple, fast, and beautiful.

---

## 🚀 Features (Seed 1)
- ✂️ Shorten URLs — fast, private, auditable  
- 🧭 Build ethical tracking links (UTM builder)  
- 🧾 Share text or notes (public, private, expirable)  
- 🧩 Generate QR codes for any link  
- 🐾 Secure file sender *(coming soon)*  

---

## 🧠 Tech Stack (Planned)
- **Frontend / Backend:** [Expo Router API Routes](https://docs.expo.dev/router/reference/api-routes/)  
- **UI:** [Tamagui](https://tamagui.dev)  
- **Language:** TypeScript  
- **Package Manager:** yarn  

---

## 🌈 Philosophy
> “You shouldn’t have to trade privacy for insight, or simplicity for power.”  
Click! is open, transparent, and ethical — built for teams and creators who care.
